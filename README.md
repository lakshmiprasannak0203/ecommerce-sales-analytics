\# E-Commerce Sales Analytics



\## Project Overview

This project focuses on analyzing e-commerce sales data to identify business insights and understand sales performance, customer behaviour, product categories, and geographical trends.



The project demonstrates practical data analytics skills through data preparation, analysis, and interactive dashboard development.



\## Dashboard Preview



!\[E-Commerce Sales Analytics Dashboard](screenshots/Ecommerce\_Dashboard.png)



\## Project Objectives

\- Analyze overall e-commerce sales performance.

\- Understand monthly sales trends.

\- Analyze customer types and customer distribution.

\- Explore sales performance across product categories.

\- Identify geographical trends across states.

\- Build an interactive dashboard for business analysis.
